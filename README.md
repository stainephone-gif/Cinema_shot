# Cinema_shot — раскадровка видео по ключевым кадрам

`cinema_shot.py` берёт короткое видео и сохраняет в отдельную папку JPG-кадры только
в тех местах, где что-то меняется:

| Событие | Что сохраняется |
|---|---|
| Склейка (монтажный стык) | последний кадр **до** склейки и первый кадр **после** |
| Смена крупности внутри плана (деталь / крупный / средний / общий) | первый кадр новой крупности |
| Изменение числа героев в кадре | первый кадр с новым количеством |
| Начало и конец видео | первый и последний кадры |
| Опционально: кадр раз в N секунд внутри плана | флаг `--interval` |

Рядом с кадрами кладутся `manifest.csv` и `manifest.json` (кадр, таймкод, номер плана,
число людей, крупность, причина), а с флагом `--contact-sheet` — общая картинка
`contact_sheet.jpg` из миниатюр.

## Установка

```bash
pip install -r requirements.txt
```

Нужен Python 3.9+ и OpenCV не ниже 4.5.4 (проверено на 4.x и 5.0). Модель детектора лиц
YuNet лежит в `models/`; если её нет, она скачивается автоматически при первом запуске.
ffmpeg не требуется.

## Использование

```bash
python cinema_shot.py clip.mp4
```

Кадры появятся в папке `clip_storyboard` рядом с видео. Имена файлов:

```
0001_shot01_00-00-00.000_start.jpg
0002_shot01_00-00-02.360_cut_before.jpg
0003_shot02_00-00-02.400_cut_after.jpg
0004_shot02_00-00-05.280_size_change.jpg
0005_shot02_00-00-07.600_count_change.jpg
```

Полезные варианты:

```bash
python cinema_shot.py clip.mp4 -o storyboard --contact-sheet   # своя папка + простыня
python cinema_shot.py clip.mp4 --interval 3                     # плюс кадр каждые 3 с внутри плана
python cinema_shot.py clip.mp4 --cut-threshold 0.25             # ловить более мягкие склейки
python cinema_shot.py clip.mp4 --stable 20                      # реже реагировать на смену крупности
python cinema_shot.py clip.mp4 --detect-every 3                 # быстрее: лица ищутся в каждом 3-м кадре
python cinema_shot.py clip.mp4 --bodies                         # дополнительно считать фигуры людей (OpenCV 4.x)
```

Все параметры: `python cinema_shot.py -h`.

## Как это работает

1. **Склейки.** Для каждого кадра считается различие с предыдущим (гистограмма HSV +
   попиксельная разница уменьшенной картинки). Склейка фиксируется, если различие выше
   порога `--cut-threshold` и заметно выше, чем у соседних кадров (`--cut-ratio`), — так
   быстрые панорамы и движение в кадре не принимаются за стык.
2. **Крупность.** Определяется по высоте самого большого лица относительно высоты кадра:
   деталь (> 55 %), крупный (> 28 %), средний (> 12 %), общий. Если лиц нет — «без лиц».
3. **Число героев.** Число найденных лиц (с `--bodies` — максимум из числа лиц и фигур).
4. **Устойчивость.** Крупность и число людей считаются изменившимися только если новое
   состояние держится в окне из `--stable` кадров (по умолчанию 12 ≈ полсекунды при 25 к/с),
   чтобы одиночные ошибки детектора не плодили лишних кадров.

## Ограничения

* Герои определяются по лицам: человек спиной к камере или сильно в профиль может не
  учитываться. Флаг `--bodies` частично помогает, но HOG-детектор есть только в OpenCV 4.x.
* Плавные переходы (наплывы, затемнения) не выделяются как отдельная склейка; обычно они
  всё равно ловятся как смена крупности/числа героев в новом плане.
* Подписи на `contact_sheet.jpg` латиницей (ограничение шрифтов OpenCV): `CU` — крупный,
  `MS` — средний, `WS` — общий, `ECU` — деталь, `NF` — без лиц, `x2` — число людей.
